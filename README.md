# Distributed-System-Stimulator

A visual simulator demonstrating distributed systems concepts: consistent hashing, replication, leader election, and network partitions.

## Features
- Visual representation of distributed nodes
- Interactive consistent hashing ring
- Raft consensus algorithm simulation
- Network partition visualization
- Real-time metrics dashboard

## Tech Stack
- **Backend**: Go
- **Frontend**: React + TypeScript + D3.js
- **Deployment**: Docker + AWS
